## PH-03. API 하나씩 직접 검증

depends on: PA-10

이전 대화에서 요청한 대로 — "기능 하나씩, API 하나씩 직접 검증". 에이전트가 자동 테스트(REST Docs
스니펫·모듈 테스트)로 계약을 검증해두지만, 실제 화면 흐름과 Figma 대조는 사람이 진행한다.

- [ ] 작가 페이지 포트폴리오 lazy 생성 → 조회 → 작품 추가/제거
- [ ] 공유(LIVE) 포트폴리오 생성 → 공유 링크 비로그인 열람 → 원본 작품 수정 시 실시간 반영 확인
- [ ] 고정형(SNAPSHOT) 포트폴리오 생성 → 원본 작품 수정·삭제 후에도 스냅샷 불변 확인
- [ ] 복제 → 삭제되거나 비공개인 작품이 자동 선택에서 빠지고 개수가 맞게 나오는지 확인
- [ ] 스타터 계정으로 SHARED 생성 시도 → 403 확인 → `subscriptions` 테이블에 직접 PRO row를 넣고 재시도 →
      성공 확인(Stripe 미연동 상태이므로 이 방법으로만 프로 전환 가능, `billing-module-design.md` 참고)
- [ ] Figma `UI개편_마이페이지_작가_수정페이지`(4971:25431) 화면과 응답 필드 대조
