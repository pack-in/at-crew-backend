# 공유 링크 미리보기(OG) 프론트 연동 요청서

서버가 공유 미리보기 이미지(1200×630 JPEG)를 만들어 R2에 저장하고, 응답에 그 key를 내려준다. 설계와 결정 근거는
[og-image-design.md](og-image-design.md).

## 1. 플랫폼별 이미지는 만들지 않는다

기획서는 "초기 배포는 공통 OG 이미지 1종"이고 "비율별 이미지 파일을 준비해 두는 것만으로 공유 플랫폼별 자동 선택이
이루어지지는 않는다"고 정했다. og:image는 플랫폼이 고르는 값이 아니라 URL 하나를 박아 두는 값이라, 플랫폼별 파일이
있어도 쓸 곳이 없다. `twitter:image`도 같은 URL을 쓴다.

## 2. 응답 필드

| API | 필드 | 의미 |
|---|---|---|
| `GET /api/artworks/{artworkId}` | `data.ogImageKey` | 이 작품의 OG 이미지 key. 성인물이면 이미 블러본이다 |
| `GET /api/portfolios/shared/{identifier}` | `data.ogImageKey` | 담긴 작품 중 외부 열람 가능한 업로드 최신 1개의 OG key. 성인물이면 블러본 |

- 이미지 URL은 기존 썸네일과 같은 방식이다: `https://asset.at-crew.com/` + `ogImageKey`.
- **null이면 서비스 기본 이미지**를 쓴다. 지정 썸네일이 없거나, 처리 중이거나, 생성에 실패했거나, 포트폴리오에 작품이 없는 경우다.
- 성인물 판정·블러는 서버가 이미 했다. FE가 `ageRating`으로 다시 고르지 않는다.
- 썸네일 교체·연령 등급 변경 시 key 자체가 바뀌므로 `?v=` 같은 파라미터를 붙이지 않는다.

## 3. 요청 사항

1. **작품 상세** `app/artwork/[artworkId]/page.tsx`의 `generateMetadata`에 `openGraph`·`twitter`를 추가한다.
   지금은 `title`만 있어 미리보기 이미지가 아예 없다.
   - `og:image`·`twitter:image` = 위 URL(null이면 기본 이미지), `twitter:card=summary_large_image`.
   - 제목·설명·URL 문구는 기획서 표를 따른다(작품 제목 / "{작가명}님의 작품을 확인해보세요." 언어별 고정 문구).
2. **포트폴리오** `app/portfolio/[slug]/page.tsx`의 `getPortfolioOgImageUrl`(FE가 목록에서 최신 작품을 고르는 로직)을
   헤더 응답의 `ogImageKey`로 바꾼다. FE 쪽 선정은 기획서와 어긋난다:
   - 비로그인 목록 응답은 성인물을 빼고 내려오므로 FE는 "성인물이면 블러본" 규칙을 지킬 수 없다.
   - 목록 50개만 받아 고르므로 업로드 최신 작품이 그 안에 없을 수 있다.
   - 지금 넘기는 `thumb/*.avif`는 세로 588×784 AVIF라 크롤러가 못 읽거나 크게 잘린다.
3. **접근이 막힌 대상은 OG를 넣지 않는다.** 작품 상세가 404·403·410(비공개·삭제·차단)이거나 포트폴리오 헤더가
   404·410이면 **기본 이미지도 넣지 않는다** — 기획서 "서비스 공통 OG로 대체하지 않으며 제목·작가명·설명·썸네일을
   외부 크롤러에 제공하지 않는다".
4. **기본 이미지 교체.** 지금 쓰는 `public/assets/artwork/community-banner.png`는 1136×330이라 기획서 규격과 맞지 않는다.
   디자인에서 1200×630 JPG·PNG를 받아 교체한다.
5. 루트 layout에 전역 기본 `openGraph.images`를 두면 다른 페이지도 기본 이미지를 물려받는다. 단, 자식 페이지가
   `openGraph`를 정의하면 통째로 교체되므로 위 1·2는 각자 지정해야 한다.

## 4. 확인

배포 후 카카오 공유 디버거, 페이스북 공유 디버거, X 게시 미리보기, 슬랙 붙여넣기로 일반 작품·성인물이 최신인
포트폴리오(블러)·작품 0개 포트폴리오(기본 이미지)·비공개 작품(OG 없음)을 확인한다.
