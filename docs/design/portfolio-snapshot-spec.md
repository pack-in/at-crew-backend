◼︎ 원본 작품의 공개 여부는 작품 피드 공개 여부와 실시간 반영 포트폴리오 포함 여부로 계산한다. 여기서 실시간 반영 포트폴리오는 작가 페이지 포트폴리오와 최신 반영형 포트폴리오만 의미한다. 작품 피드에 공개하거나 실시간 반영 포트폴리오에 1개 이상 포함된 원본 작품은 정식 작품 상세 URL의 제3자 접근을 허용한다.
◼︎ 고정형 포트폴리오 포함은 원본 작품의 공개 위치로 계산하지 않는다. 고정형에서 공개되는 자원은 생성 시점의 독립된 작품 스냅샷이며, 원본 작품의 공개 상태·정식 작품 상세 URL 접근 권한을 변경하지 않는다(마이페이지_작가-R39).
◼︎ "작성자 비공개" 또는 "완전 비공개"는 사용자가 선택하는 단일 상태가 아니라, 원본 작품이 작품 피드 공개 OFF이면서 실시간 반영 포트폴리오 포함 수가 0개일 때 계산되는 파생 상태다. 문서에서는 이를 "원본 공개 위치 없음"으로도 표현한다. 고정형 스냅샷 참조 수는 이 계산에 포함하지 않는다.
◼︎ 작품 피드에 공개하기가 켜진 작품은 홈 작품피드·작품 검색·태그 탐색과 작품 상세 URL을 통해 누구나 접근할 수 있다. 포트폴리오에도 체크한 경우에는 해당 포트폴리오에서도 함께 노출한다.
◼︎ 작품 피드에 공개하기가 꺼져 있어도 작가 페이지 포트폴리오 또는 최신 반영형 포트폴리오에 1개 이상 포함되어 있으면 홈 작품피드·작품 검색·태그 탐색에는 노출되지 않지만, 해당 포트폴리오와 원본 작품 상세 URL을 통해 접근할 수 있다.
◼︎ 작품 피드에 공개하기가 꺼져 있고 실시간 반영 포트폴리오에도 포함되지 않은 원본 작품은 홈 작품피드·작품 검색·태그 탐색·실시간 반영 포트폴리오·원본 작품 상세 URL의 제3자 접근 어디에도 노출·허용되지 않으며, 본인에게만 노출·접근을 허용한다. 고정형에 해당 작품의 스냅샷이 존재하더라도 원본 접근 제한은 유지된다. 원본 공개 위치와 무관하게 작품 고유 ID와 정식 URL 자체는 작품 저장 완료 시 생성·유지하며, URL 생성과 제3자 접근 권한을 분리한다(작품 상세 페이지-R01).
◼︎ 직접 접근이 가능하던 작품이 이후 완전 비공개(작품 피드 OFF + 포트폴리오 전부 미체크)로 전환된 경우, 이전에 공유된 작품 상세 링크로 접근하더라도 더 이상 열람할 수 없다.
◼︎ 작품 관리 화면(마이페이지_작가-R47)에서는 공개 위치와 무관하게 본인의 모든 작품을 노출한다. 작품 카드에는 노출 상태를 나타내는 칩을 제공하지 않는다.
◼︎ 포트폴리오 관리 > 작가 페이지 포트폴리오 화면(마이페이지_작가-R13)에는 업로드·수정 화면 또는 작품 관리 화면의 [포트폴리오에 추가하기]에서 작가 페이지 포트폴리오를 체크한 작품만 노출된다(업로드-R09, 마이페이지_작가-R14·R47 참조).
◼︎ 타인 페이지(작가 페이지), 기업 계정 뷰, 비로그인 뷰에서는 작가 페이지 포트폴리오에 포함된 작품만 작가 페이지 그리드에 노출한다.

◼︎ 화면 제목은 "작품 공개 방식을 선택해주세요"이다.
◼︎ 사용자에게 전체공개·링크공개·비공개 같은 추상적인 공개 상태값을 직접 선택하게 하지 않는다. 사용자는 실제 노출 위치를 선택하고, 시스템이 선택 조합에 따라 작품 상태를 결정한다.
◼︎ 이 화면은 업로드 플로우의 마지막(11번째) 단계이며, 작품 피드 공개 여부와 포트폴리오 선택을 모두 이 화면에서 설정한다. "앳크루 작품 피드에 공개하기" 항목과 포트폴리오 선택 항목은 같은 화면에 함께 노출되지만 서로 독립적인 설정이며, 하나를 선택해도 다른 하나에 영향을 주지 않는다. 포트폴리오에 추가하기 항목은 요금제와 무관하게 모든 사용자에게 노출된다.
◼︎ 작품 피드 공개 여부 항목은 칩(Chip) 형태의 2지선다로 제공한다.
작품 피드에 공개하기(기본값으로 이미 선택된 상태, 검정 배경 칩)
작품 피드에 공개하지 않기(미선택 기본 상태, 흰색 배경 칩)
◼︎ 진입 시 공개하기 칩이 기본값으로 선택되어 있으며, 사용자가 별도로 변경하지 않는 한 이 상태가 유지된다. 공개하기가 선택된 경우 해당 작품은 홈 작품피드·전체 검색·태그 검색에 노출되며, 공개하지 않기를 선택하면 위 화면들에 노출되지 않는다.
◼︎ 작품 피드 공개 여부 항목은 작품 업로드 전용이며, 구인글·팀원 모집글에는 적용되지 않는다.
◼︎ "포트폴리오에 추가하기" 항목은 칩 형태의 2지선다로 제공한다.
포트폴리오에 추가하기
포트폴리오에 추가하지 않기
◼︎ [포트폴리오에 추가하기]를 선택하면 하단에 포트폴리오 목록이 그리드로 노출되며, 각 포트폴리오 카드에는 체크박스가 있어 다중 선택할 수 있다.
◼︎ 포트폴리오 목록 첫 번째 항목은 항상 "작가 페이지 포트폴리오"이며 "기본" 배지를 노출한다. 스타터·프로 플랜 모두에게 노출되며, 다른 카드와 동일하게 체크박스로 선택·해제한다.
◼︎ 스타터 플랜 사용자에게는 목록에 "작가 페이지 포트폴리오" 카드만 노출된다. 사용자 생성 포트폴리오는 프로 플랜 전용이므로 노출하지 않는다. 다만 프로에서 스타터로 다운그레이드된 계정은 예외로, 이미 생성해둔 기존 공유 포트폴리오가 목록에 비활성화(disabled) 상태로 함께 노출된다(요금제-R01).
◼︎ 프로 플랜 사용자에게는 "작가 페이지 포트폴리오" 카드 아래로 본인이 생성한 최신 반영형 포트폴리오가 체크박스 카드로 함께 노출되며, 다중 선택할 수 있다. 고정형 포트폴리오는 생성 이후 작품을 추가할 수 없으므로 이 목록에 노출하지 않는다(마이페이지_작가-R38과 동일 기준).
◼︎ [포트폴리오에 추가하기]를 선택했지만 목록에서 포트폴리오를 하나도 체크하지 않은 상태로 [업로드하기]를 시도하면 다음 안내를 노출한다(마이페이지_작가-R38과 동일 문구 재사용).
작품을 추가할 포트폴리오를 하나 이상 선택해주세요.
◼︎ 공개 위치 조합별 처리 결과는 다음과 같다.
작품 피드에 공개하기 ON(포트폴리오 선택 여부 무관): 홈 작품피드·전체 검색·태그 검색에 공개되며, 체크한 포트폴리오(작가 페이지 포트폴리오 포함)에도 함께 포함된다.

작품 피드에 공개하기 OFF + 포트폴리오도 하나도 체크하지 않음: 완전 비공개로 저장된다(어디에도 노출되지 않음).
◼︎ 기능 명세와 데이터에서 사용하는 "작성자 비공개" 또는 "완전 비공개"는 사용자가 별도로 고르는 단일 공개 상태가 아니라, 원본 작품이 작품 피드 공개 OFF이면서 작가 페이지 포트폴리오·최신 반영형 포트폴리오 포함 수가 0개일 때 계산되는 파생 상태다. 문서에서는 이를 "원본 공개 위치 없음"으로도 표현한다. 고정형 포트폴리오의 스냅샷 참조는 원본 작품의 포트폴리오 포함 수나 공개 상태에 합산하지 않는다.
◼︎ 작품 업로드 완료 후 이동 화면은 작품 피드 공개 여부와 포트폴리오 선택 조합에 따라 다음과 같이 분기한다.

작품 피드에 공개하기 ON + 작가 페이지 포트폴리오는 미선택, 다른 포트폴리오를 여러 개 선택: 마이페이지 > 프로필 관리가 선택된 화면으로 이동한다.
작품 피드에 공개하기 ON + 작가 페이지 포트폴리오는 미선택, 다른 포트폴리오 중 정확히 1개만 선택: 마이페이지 > 프로필 관리가 선택된 화면으로 이동한다.
작품 피드에 공개하기 OFF + 작가 페이지 포트폴리오만 선택: 작가 페이지 포트폴리오 세부 화면으로 이동한다(새 탭).
작품 피드에 공개하기 OFF + 작가 페이지 포트폴리오는 미선택, 다른 포트폴리오 중 정확히 1개만 선택: 해당 포트폴리오 세부 페이지로 이동한다(새 탭).

작품 피드에 공개하기 OFF + 포트폴리오를 하나도 선택하지 않음(완전 비공개): 마이페이지 > 작품 관리가 선택된 화면으로 이동한다.
위 분기는 신규 작품 업로드에만 적용하며, 구인글·팀원 모집글 업로드는 업로드-R01의 일반 규칙(상세 페이지로 이동)을 따른다. 기존 작품 수정 완료 후에는 수정 진입 위치나 공개 위치 조합과 관계없이 수정한 작품 상세 페이지로 이동한다(마이페이지_작가-R18).
◼︎ 위 조합별 처리 결과 외의 예외 처리 세부 규칙은 마이페이지_작가-R37(포트폴리오 관리)을 따른다.
◼︎ 이미지 나열 형식·연령대·게시물 작성·노출 언어 설정은 이전 단계(작품 설정, 6번째 단계)에서 다루며, 업로드-R30을 따른다.
◼︎ 작품 피드에 공개하지 않으면서 작가 페이지 포트폴리오 또는 최신 반영형 포트폴리오에 1개 이상 포함된 원본 작품은 정식 작품 상세 URL로 직접 접근할 수 있다. 작품 피드에 공개하지 않고 실시간 반영 포트폴리오에도 포함되지 않은 원본 작품도 정식 URL은 생성·유지하지만 제3자의 직접 접근은 차단한다.
◼︎ 고정형 포트폴리오는 업로드 단계의 선택 목록에 노출하지 않으며, 이후 고정형 생성 과정에서 해당 작품을 선택해도 원본 작품의 공개 상태와 정식 작품 상세 URL 접근 권한은 바뀌지 않는다. 고정형에서는 생성 시점의 별도 스냅샷과 포트폴리오 전용 상세 URL만 공개한다(마이페이지_작가-R39). 상세 URL 생성은 작품 상세 페이지-R01, 접근 권한은 마이페이지_작가-R04를 따른다.
